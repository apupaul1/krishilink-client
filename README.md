# 🌾 KrishiLink Client

Frontend application for **KrishiLink**, a modern agricultural marketplace that connects farmers directly with customers for a transparent and efficient buying experience.

---

## 🚀 Features

- 🔐 Firebase Authentication
- 👨‍🌾 Farmer Dashboard
- 🛒 Customer Shopping Experience
- 📦 Product Management
- 📱 Fully Responsive UI
- 🎨 Modern Design with Tailwind CSS & Ant Design
- ⚡ Fast Performance with React & Vite
- 🔄 Real-time API Integration

---

## 🛠️ Tech Stack

- React
- TypeScript
- Vite

## ⚙️ Environment Variables

Create a `.env.local` file and add:

```env
VITE_API_URL=http://localhost:5000/api/v1

VITE_FIREBASE_API_KEY=your_api_key

VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain

VITE_FIREBASE_PROJECT_ID=your_project_id

VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket

VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id

VITE_FIREBASE_APP_ID=your_app_id
```
